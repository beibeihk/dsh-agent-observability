# Security reporting

Do not include real credentials, private prompts or exploit details in public issues. For this plugin, contact the maintainer at the public address `huangkun123huang@163.com` with a minimal sanitized reproduction and the affected version. For an upstream Harness issue, follow its current security/safety reporting guidance instead of posting a public Discussion.

Metadata mode is the default, but identifiers/tool names can still be sensitive. Content mode redaction is pattern-based, not a general personal-data classifier. Review exports before sharing them. The plugin does not change the privacy behavior of upstream session persistence or telemetry. See [privacy](docs/privacy.md).
